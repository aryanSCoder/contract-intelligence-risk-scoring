# AI-Powered Contract Intelligence & Risk Scoring

An AI-powered application that analyzes contract documents, detects important clauses, identifies potential contractual risks, and supports semantic search across contract sections.

## Features

* **Contract ingestion:** Process PDF contract documents.
* **Clause detection:** Identify relevant clauses using a rule-based detection pipeline.
* **Risk scoring:** Generate risk scores and highlight potentially concerning contractual terms.
* **Semantic search:** Search contract sections using natural-language queries and sentence embeddings.
* **Risk reports:** Review detected clauses and risk analysis through API endpoints.
* **Contract metadata:** Retrieve file size, SHA-256 hash, and modification timestamp for uploaded contracts.
* **Web interface:** Upload contracts and review analysis results.
* **API documentation:** Explore available endpoints through FastAPI Swagger UI.

## Technology Stack

* Python
* FastAPI and Uvicorn
* pandas and NumPy
* scikit-learn and spaCy
* PyTorch and Transformers
* Sentence Transformers
* FAISS
* PDF processing and OCR utilities
* HTML, CSS, and JavaScript

## Project Setup

### 1. Clone the repository

```bash
git clone https://github.com/aryanSCoder/contract-intelligence-risk-scoring.git
cd contract-intelligence-risk-scoring
```

### 2. Create a virtual environment

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The semantic search feature requires the FAISS index and metadata files generated by the project's vector-index builder. The sentence-transformer model may need to be downloaded on first use.

### 4. Prepare the semantic search index

Ensure the processed contract sections are available, then run:

```powershell
python src/build_vector_index.py
```

This generates the vector index and metadata under `data/processed/vector_index/`.

### 5. Start the application

```powershell
uvicorn app.main:app --reload
```

Open the following URLs in your browser:

* Application: http://127.0.0.1:8000/
* Swagger API documentation: http://127.0.0.1:8000/docs
* Health check: http://127.0.0.1:8000/health

## API Endpoints

| Endpoint                                   | Purpose                               |
| ------------------------------------------ | ------------------------------------- |
| `GET /`                                    | Open the web interface                |
| `GET /api`                                 | List API information                  |
| `GET /health`                              | Check application health              |
| `POST /upload-contract`                    | Upload a PDF contract                 |
| `POST /analyze-contract`                   | Analyze a PDF contract                |
| `POST /search`                             | Search contract sections semantically |
| `GET /contract-metadata/{stored_filename}` | Retrieve uploaded-file metadata       |
| `GET /risk-report`                         | Retrieve the risk report              |
| `GET /detected-clauses`                    | Retrieve detected clauses             |
| `GET /risk-details`                        | Retrieve risk details                 |
| `GET /download-report`                     | Download the generated report         |

Refer to Swagger UI for request formats and response schemas.

## Important Limitations

* Risk scores are automated indicators and should not be treated as legal advice.
* Clause detection and model predictions may produce false positives or miss relevant terms.
* Semantic search requires the matching vector index, metadata, and embedding model.
* PDF extraction and OCR results depend on document quality and available system dependencies.
* Review important contract decisions with a qualified legal professional.
