\# AI-Powered Contract Intelligence \& Risk Scoring



An NLP-based system for analyzing commercial contracts, extracting key entities and clauses, and identifying potentially high-risk contract language.



\## Project Goals



\- Contract document ingestion

\- Entity extraction

\- Legal clause identification

\- Risk-oriented language analysis

\- Semantic contract search

\- API-based inference

\- Production-oriented deployment



\## Dataset



CUAD (Contract Understanding Atticus Dataset).



\## Technology



\- Python

\- spaCy

\- PyTorch

\- Hugging Face Transformers

\- FastAPI

\- Vector Database

\- Docker
